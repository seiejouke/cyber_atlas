# Implementation references

The application is original prototype code. These primary sources document the
underlying libraries and platform setup, rather than serving as a cybersecurity
curriculum.

- Python / Tkinter: https://docs.python.org/3/library/tkinter.html
- VTK 9.6.2 package and platform wheels: https://pypi.org/project/vtk/9.6.2/
- VTK Python wrappers: https://docs.vtk.org/en/v9.6-final/advanced/PythonWrappers.html
- VTK getting started and graphics requirements: https://docs.vtk.org/en/v9.6.2/getting_started/index.html
- VTK surface picking: https://vtk.org/doc/nightly/html/classvtkCellPicker.html
- Arch's Tk package: https://archlinux.org/packages/extra/x86_64/tk/

The prototype's example concepts carry forward the user's earlier HTML atlas.
Explicit block sizes and angular slots replace its fixed protocol sectors. Layer and depth
are editable learning-map choices, not a strict assertion of OSI conformance.
